# Dotfiles Configuration

Personal system configuration files with multi-environment support.

## About

Cross-platform development environment configurations including terminal, editor, and development tool settings. Uses branch-based management for different use cases.

## Branches

| Branch      | Function                                                                      |
| ----------- | ----------------------------------------------------------------------------- |
| `main`      | Base configuration for merging into other branches                            |
| `macos`     | macOS host system configuration with Zsh, Tmux, WezTerm settings              |
| `dev`       | development container configuration with Nvim, Tmux, AI tool settings         |
